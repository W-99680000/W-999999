# 质量路线图：稳定性 · 实时性 · 翻译准确性

对象：`live-subtitle`（两个模块：**直播翻译** loopback / **视频翻译** cache）
版本：2026-10-18 · 分支 `opt/2026-10-18`
配套：`docs/RESEARCH_20261018_streaming_translation.md`（全网调研）、
`tools/quality_report.py`（基线统计）、`tools/doctor.py`（环境体检）。

## 0. 消费级目标（验收门槛）

| 维度 | 指标 | 目标 |
|---|---|---|
| 稳定性 | 连续运行 8h 崩溃/退出 | **0 次**；无残留进程、无浮窗残影 |
| 稳定性 | 启动成功率（GPU/CPU/无网三种环境） | 100%，失败有可读原因 |
| 实时性（直播） | 首字延迟 P50 / P90 | ≤ 2.0s / ≤ 3.0s |
| 实时性（直播） | 端到端延迟 P50 / P90（音频说出→字幕上屏） | ≤ 1.5s / ≤ 2.5s |
| 实时性（视频） | 预翻译速度 | ≥ 8× 实时（48min 片 ≤ 6min） |
| 实时性（视频） | 已缓存视频首条字幕上屏 | ≤ 0.5s（缓存命中时） |
| 准确性（ASR） | 中英日韩越测试集 WER | 相对当前基线 ↓ ≥ 10% |
| 准确性（MT） | COMET / 人工抽检 | 不低于当前基线；术语命中率 ≥ 95% |
| 可读性 | 字幕 CPS（字/秒） | 中文 ≤ 9，英文 ≤ 15；单行 ≤ 42 字符（参考 Netflix/BBC） |
| 资源 | GPU 显存峰值 | ≤ 7.2GB（8GB 卡留余量）；CPU 回退可用 |

| 视频预翻译速度 | 约 0.16× 音频时长（52min ≈ 8.4min） | `watch.log` / autopipe 估算 |

## 2. 度量体系（先度量，再优化）

1. **直播批量指标（已实现）**：`work/metrics_live.jsonl`
   - 字段：`asr_s`、`audio_s`、`shown`、`shown_total`、`lang`、`lang_p`、`gate`、`rejected`、`ready_s`
   - 统计：`python tools/quality_report.py`（P50/P90、吞吐、拒段、启动）
2. **端到端延迟（P0，待实现）**：给每个 segment 记"音频时间轴 → 上屏墙钟"，产出
   `lag_s = t_show - (t_capture_epoch + audio_pos)`；目标 P50/P90 直接可算。
3. **视频翻译指标（P0，待实现）**：`work/metrics_cache.jsonl`：每块 `audio_s / asr_s / mt_s / cues`、
   首块落盘时间、缓存命中/续跑、最终 complete。
4. **准确性评测（P0，待实现）**：
   - ASR：固定 4 语种小测试集（各 3–5 分钟，人工校对原文），算 WER/CER；
   - MT：同一批人工参考译文，算 COMET（或 chrF/BLEU 兜底）+ 术语命中；
   - 回归：`bench/` 加 `bench_accuracy.py`，输出 JSON 与基线对比。
5. **稳定性**：8h soak（循环播放样本+随机暂停/切语言/断网）、崩溃自动记录
   （`work/crash/` 保存最后 200 行日志 + traceback）。

## 3. 改进清单（按优先级）

### P0（先做，收益大/风险低）

| # | 项 | 模块 | 收益 | 验证 |
|---|---|---|---|---|
| P0-1 | 端到端延迟埋点 + 报表（上文 §2.2） | 直播 | 让"实时性"从感觉变成数字 | 样本播放 3 轮，P50/P90 稳定 |
| P0-2 | 静音边界提前发批（flush-on-silence） | 直播 | 首字延迟 −0.3~0.8s（稀疏语音） | 同一素材 A/B 首字延迟 |
| P0-3 | 崩溃自恢复：引擎/浮窗异常退出自动重启（带退避） | 双模块 | 长跑稳定性；消费级必备 | 强杀引擎，5s 内自动恢复且浮窗不残影 |
| P0-4 | 设置/缓存文件原子写 + 校验（防半截 JSON 导致启动失败） | 双模块 | 稳定性 | 写坏 JSON 后启动仍成功 |
| P0-5 | 准确性评测脚手架（WER/CPS/术语） | 双模块 | 后续优化的判据 | 基线报告入库 |
| P0-6 | 视频：半截缓存续跑 + 断点 meta 已在，补"完成度/覆盖分钟"进度提示 | 视频 | 用户知道在补哪一段 | 已实测（4→10 条） |

### P1（做完 P0 后）

| # | 项 | 模块 | 收益 | 风险/备注 |
|---|---|---|---|---|
| P1-1 | 计算类型矩阵（float16/int8_float16）+ large-v3-turbo 选项 | 双模块 | 同延迟更准或同精度快 1.3–2× | 需 A/B WER；8GB 显存实测 |
| P1-2 | 视频预翻译用 `BatchedInferencePipeline` | 视频 | 吞吐 2–3× | 需关 `condition_on_previous_text`，质量需 A/B |
| P1-3 | 远端/本地翻译路由与术语表强化（上下文、专名、数字格式） | 双模块 | 准确性 | 有 API 成本；需评测集 |
| P1-4 | VAD/端点检测（Silero 或现有 DSP 门升级） | 直播 | 漏句↓、误切↓ | 需与现有噪声门 A/B，避免延迟上升 |
| P1-5 | 字幕可读性后处理（CPS 压缩/断行/标点） | 双模块 | 观感与可读性 | 中文压缩可能丢信息，需人工抽检 |
| P1-6 | 打包/自动更新/崩溃上报（消费级） | 桌面 | 交付质量 | 见 `docs/DESKTOP.md` |

### P2（择优）

- 流式 ASR（LocalAgreement/SimulStreaming）替换分块批处理——调研报告给出适用性；
- 端侧小模型（Moonshine/Parakeet/turbo）作为低配模式；
- 视频翻译按"当前播放位置优先"的分块排序（需改 SRT 写入顺序/让 watch 容错乱序）；
- 多人声/音乐场景的源分离（人声增强）预处理器；
- 多屏/远程字幕（手机端查看）。

## 4. 稳定性测试矩阵

| 场景 | 操作 | 期望 |
|---|---|---|
| 冷启动 CPU | 禁用 GPU | ready ≤ 20s，CPU 回退提示 |
| 冷启动 GPU | 正常 | 浮窗先出，ready ≤ 6s |
| 断网 | 拔网/代理失效 | 本地模型可用；远端自动回退；日志有原因 |
| 长跑 | 8h 循环 | 无崩溃/无内存增长/无残影 |
| 强杀 | kill 引擎/浮窗 | 自动恢复或干净退出，无残留进程 |
| 切换视频 | 连续切 3 部 | 旧任务被杀，新字幕 ≤5s |
| 拖动进度 | 连续 seek | 字幕 ≤300ms 重新对齐 |
| 缓存损坏 | 截断 srt/meta | 识别为半截并续跑，不崩溃 |

## 6. 调研落地清单（2026-10-18 全网调研，详见 docs/RESEARCH_20261018_streaming_translation.md）

调研结论：**先补三件工程件（术语表、字幕规整、幻觉闸门），再谈换算法。**
下面按"收益确定、改动局部"排序回填到 §3：

- **P0-1 术语表接到 Qwen-MT 的 	ranslation_options**：llm_translate.py 目前请求体只有
  model/prompt/stream，未带术语参数（官方支持，注释里也写了）→ 0.5–1 人日；
  验证：50 句术语集（术语正确率 + COMET + P50）。
- **P0-2 字幕规整层**：SRT 现在是固定 hold=6s，不是语音真实结束时间；用
  word_timestamps 算真实区间，按 42 字符/行、≤2 行、CPS 上限（英文 ≤20，
  中文 16–20 字/行，阈值可配）切分与压缩 + 最小停留时长 → 2–3 人日。
- **P0-3 幻觉硬闸门**：输出侧四道闸（
o_speech_prob/vg_logprob 组合、
  重复率、连续重复短语、无 VAD 不送 ASR）→ 0.5 人日；对抗集：纯静音/音乐/
  游戏音效各 10min，目标"每分钟假句数 = 0"。
- **P1-1 ASR→MT 双缓冲流水线**：ASR 完成立即入 MT 队列（带 context），显示层按
  batch_id 顺序替换；理论端到端 1.0→0.7s，需实测 GPU 争用。
- **P1-2 视频模块批推理**：官方基准 13min 音频 63s→17s（batch=8，VRAM 6.1GB；
  int8 4.5GB，8GB 卡可跑）；需 A/B 时间轴与断点续跑一致性。
- **P1-3 时间轴规整**：借鉴 stable-ts 的 silence suppression / adjust_gaps
  （只借算法），或 WhisperX 强制对齐（+wav2vec2 体积）。
- **P2-1 远端连接复用/限流**：Qwen3-ASR RPM 100、Qwen-MT RPM 60/TPM 35k；
  连接池 + 令牌桶 + 429 退避。
- **P2-2 浮窗可读性**：对比度 ≥4.5:1（大字 3:1），不透明度下限。
- **P2-4 缓存一致性**：meta 加模型/参数指纹，避免新旧模型拼接续跑。

**暂不做**：把直播模块换 SimulStreaming/AlignAtt 原版 —— 需要模型内部
cross-attention（faster-whisper 不提供）且推荐 ≥10GB 显存（本机 8GB）；
先按上面 P0/P1 拿到确定收益，再决定是否做 POC。
